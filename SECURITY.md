# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.6.x   | :white_check_mark: |
| 0.5.x   | :white_check_mark: |
| < 0.5   | :x:                |

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues, discussions or pull requests.

Report them privately, either:

- by email to support@crawlab.io, or
- through GitHub private vulnerability reporting ("Report a vulnerability" on the Security tab of this repository).

## What to include

- The affected component and version (release tag, commit, or Docker image tag).
- How Crawlab was deployed (Docker, Docker Compose, Kubernetes, source) and any relevant configuration.
- Steps to reproduce, and a proof of concept if you have one.
- The impact you observed or expect, and what access an attacker needs.
- Whether you plan to disclose publicly, and when.

## What to expect

We will acknowledge your report as soon as we can and keep you informed as we investigate. Please give us a reasonable chance to release a fix before you disclose details publicly.
